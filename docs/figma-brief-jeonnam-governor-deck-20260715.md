## 프롬프트 (여기서부터 복사)

당신은 정부·공공기관 최고위급 브리핑 덱을 전문으로 하는 프레젠테이션 디자이너입니다.
**전라남도지사에게 직접 보고되는 15분 브리핑 덱**을 제작합니다.

# 1. 프로젝트 개요

- 제목: **전남 축산 AI 플랫폼 — CowTalk** (부제: 대한민국 축산 AI의 표준, 전남에서)
- 지향: 이 덱은 '한우 개량 도구' 제안이 아니라 **전남 축산 전체의 디지털 운영체제** 제안이다.
  한우는 가장 강력한 출발점(1단계 실증 축종)으로 배치한다. 추구 가치 3가지 —
  ① 목장 경제성 ② 질병 관리(방역) ③ 공공성(축산 행정의 디지털 전환) — 가 덱 전체를 관통해야 한다.
- 청중: 전남도지사 및 도 축산 정책 라인 (기술 비전문가, 의사결정권자)
- 목적: 시범사업 지정·예산·데이터 연계 협조라는 3가지 의사결정을 끌어내는 것
- 분량: 16:9 슬라이드 **14장**
- 언어: 한국어 (전문용어는 쉬운 말로 풀어쓰기)
- 톤: 신뢰·절제·정직. 스타트업 피치가 아니라 **도정 보고서의 품격 + 프리미엄 테크 브랜드의 완성도**

# 2. 디자인 시스템

- 포맷: 1920×1080, 여백 넉넉히(최소 96px 마진), 슬라이드당 핵심 메시지 1개
- 색상:
  - 베이스: 딥 네이비 `#0F1B2D` (신뢰) / 배경 대비용 아이보리 `#F7F5F0`
  - 주 강조: 딥 그린 `#1B5E43` (전남·농업·생명)
  - 보조 강조: 한우 브라운-앰버 `#B4762A` (한우·수익)
  - 경고·방역: 오렌지 `#D9541E` (방역 슬라이드에만 제한 사용)
- 타이포: Pretendard (제목 Bold 54~72pt, 본문 24~28pt, 캡션 18pt). 슬라이드당 텍스트 60단어 이내
- 그래픽 스타일: 플랫 + 얇은 라인 아이콘, 실데이터 차트(막대·타임라인·지도), **스톡 클립아트·3D 일러스트·AI 느낌 이미지 금지**
- 공통 장치:
  - 모든 기능 항목에 상태 배지 부착: `✅ 지금 작동` (그린) / `🟡 실증 단계` (앰버) / `⬜ 로드맵` (그레이) — 이 배지가 이 덱의 신뢰성 장치이므로 전 슬라이드 일관 적용
  - 하단에 얇은 진행 표시줄 + 슬라이드 번호
  - 추정 수치에는 각주 “※ 전남 실측치로 보정 예정” 명기

# 3. 슬라이드별 상세

**S1 표지**
- 최상단 작은 아이라인: “대한민국 축산 AI의 표준, 전남에서”
- 큰 타이틀 (화면의 주인공, 최대 크기): **“전남 축산 AI 플랫폼”**
- 서브: 센서 알람을 농가의 행동과 도(道)의 행정으로 — 축산 디지털 운영체제 CowTalk · 전라남도지사 보고
- 배경: 딥 네이비에 전남 지도 실루엣을 얇은 라인으로, 좌하단 날짜·보고 주체

**S2 오늘 보고의 결론 (One-page summary)**
- 3개 결론 카드: ① 축산 AI 플랫폼(운영체제)이 이미 작동한다 ② 출발점은 한우 — 전남이 가장 잘 쓸 수 있다 ③ 시범사업 1~2개 시군으로 시작해 전남 축산 전체로 확장한다
- 하단 한 줄: “되는 것과 검증할 것을 구분해 보고드립니다” (정직 선언)

**S3 전남의 세 가지 현실**
- 3열 카드: ① 한우 사육 전국 최상위권 — 개량·번식은 농가 개별 역량 의존 ② 농가 고령화 — 새 시스템 학습 부담 ③ 재난형 가축전염병(구제역·럼피스킨) — 역학조사 부담
- 각 카드 아래 작은 화살표로 “CowTalk의 답” 한 줄씩

**S4 우리가 추구하는 것 — 축산 디지털 운영체제**
- 중앙 수식 다이어그램: 위내센서(smaXtec) + 국가 공공데이터 + AI 해석 + 역할별 액션플랜 = 축산 디지털 운영체제
- 수식 아래 가치 칩 3개 (덱 전체를 관통하는 추구 가치): **목장 경제성** · **질병 관리** · **공공성(축산 행정 디지털 전환)**
- 캡션: “센서가 아니라, 알람을 ‘행동’과 ‘행정’으로 바꾸는 다리 — 1개 농장에서 도(道) 전체, 국가까지 확장되는 구조”

**S5 작동 증거 — 숫자로**
- 대형 숫자 3개 (빅 넘버 레이아웃): “3초” 도내 발열 현황 집계(팅커벨 질문 1문장) / “30초” 소 이동이력 기반 접촉망 추적 / “25개” AI가 스스로 조회·기록하는 도구 수
- 하단 소형 수치 줄: 코드 13만 줄 · DB 테이블 88개 · 테스트 70건 (2026-07 코드 실사 기준)
- 전체에 `✅ 지금 작동` 배지

**S6 왜 한우가 출발점인가 — 전남에서 지금 작동하는 한우 스택**
- 4행 표: 씨수소 추천(농촌진흥청 API 연동, 근교계수 6.25% 경고) / 축산물 이력제 실시간 조회 / 등급판정·경락가격 시세 즉답 / 번식 6단계 관리(발정→수정→임신→분만)
- 각 행에 `✅ 지금 작동` 배지. 강조 카피: “젖소용을 고쳐 쓰는 게 아니라, 처음부터 한우를 위해 만들어졌습니다”
- 하단 작은 확장 화살표: 한우(1단계 실증) → 젖소·전 축종 → 도 방역·행정 통합 — “플랫폼은 축산 전체, 시작이 한우”

**S7 고령화의 답 — 말로 하는 AI**
- 좌: 스마트폰 목업에 대화 예시 (음성 말풍선: “423번 소 어때?” → AI 답변: 체온·활동·번식 상태 요약)
- 우: 포인트 3개 — 앱 조작 학습 불필요 / 음성 입출력 / 모든 답변에 데이터 출처 표기
- 카피: “어르신 농가도 첫날부터 씁니다”

**S8 방역 — 사후 대응에서 사전 차단으로**
- 좌: 전남 지도 + 확산 시뮬레이션 시각화(동심원·이동 경로 라인), 오렌지 강조
- 우: 3단계 타임라인 — 조기감지(증상 전 체온·활동 이상) → 접촉망 30초 추적 → 확산 시뮬레이션으로 이동제한 시나리오 사전 비교
- 하단: 역학조사·KAHIS 보고 기록 관리 `✅ 지금 작동`

**S9 공공이 믿을 수 있는 구조 (거버넌스)**
- 4분면 카드: 역할별 권한(농장주/수의사/방역관/행정관) / 모든 AI 행동 감사 기록 / AI 제안 → 전문가 승인 후 실행 / AI는 추측 금지·DB 수치만 인용
- 캡션: “Palantir형 거버넌스 구조를 축산 도메인에 구현” (작게, 과장 없이)

**S10 정직하게 말씀드리는 것 — 이 슬라이드가 핵심**
- 제목: “되는 것과, 전남에서 검증할 것”
- 2열 대비: 좌(✅ 지금 작동 — S5~S9 요약 리스트) / 우(🟡 실증 단계 — ① 도내 기반 농장 현재 8곳: 신규 구축 시범형으로 설계 ② 한우 위내센서 정착·알람 정확도 실증: 시범사업 1단계 검증 항목 ③ 기대효과 수치: 전남 실측으로 확정)
- 카피: “이 검증을 전남이 최초로 해내면, 전남이 대한민국 축산 AI 표준의 원산지가 됩니다”

**S11 사업 구조 — 3단계 로드맵**
- 가로 타임라인 3단계: ① 한우 실증(1년, 시군 1~2곳, 정확도·수태율 실측) → ② 개량·출하 연계(1년, 씨수소→수정→송아지→등급 루프) → ③ 도 방역망 통합(2년차~, KAHIS 연계·상시 대시보드)
- 각 단계에 검증 목표를 작은 배지로

**S12 기대효과 — 산정 구조**
- 4개 효과 카드: 농가 소득(폐사 1두 방지 = 수백만원 직접 효과) / 행정 효율(역학조사 수일→30초) / 방역 옵션가치(확산 1회 차단 = 수십~수백억 회피) / 고령화·환경(음성 AI + 사료·분뇨·탄소 저감)
- 전 카드에 각주: “※ 전남 사육두수·농가수 실측 반영 후 확정 (산정 모델 준비됨)”

**S13 전라남도에 드리는 요청**
- 번호형 3+1: ① 시범사업 지정·예산(시군 1~2곳, 번식우 중심) ② 데이터 연계 협조(KAHIS·이력제·개량 데이터) ③ 공수의사·축협 연계 체계 / +④ “전남 축산 AI 표준” 공동 브랜딩
- 의사결정 슬라이드이므로 가장 단순·대담한 레이아웃

**S14 클로징**
- 풀블리드 딥 그린 배경, 중앙 한 문장: “데이터가 가장 많은 곳이 표준을 만듭니다. 대한민국 축산 AI의 표준은 전남에서 시작됩니다.”
- 하단: 연락처·보고 주체 (플레이스홀더)

# 4. 금지 사항 (엄수)

- “세계 최초·국내 유일·혁명” 등 검증 불가 수식어 금지
- 위 슬라이드에 없는 수치 임의 생성 금지, 추정치에는 반드시 보정 각주
- “Palantir 급” 표현 금지 (“Palantir형 구조”까지만)
- 스톡 사진·클립아트·과도한 그라데이션·네온 금지
- 슬라이드당 메시지 1개 초과 금지
