# CowTalk AI 플랫폼 사업 제안서 — 경기도 (초안 v1, 2026-07-15)

> 제안 골자: 센서(smaXtec) + 국가 공공데이터 + AI 해석 + 역할별 액션플랜을 하나로 묶은
> **축산 디지털 운영체제(Livestock Digital OS)** 를 경기도가 전국 최초 광역 표준으로 도입.

## 1. 한 줄 제안

**"경기도를 대한민국 축산 디지털 행정의 첫 모델로 — 알람을 '행동'과 '행정'으로 바꾸는 운영체제."**

경기도는 이미 CowTalk 네트워크 199개 농장 중 **52곳(수도권 최대, 전국 2위)** 이 위치한,
데이터가 가장 집약된 광역지자체다. 데이터가 가장 많은 곳이 표준을 만든다.

## 2. 경기도가 가진 문제 (행정 관점)

| 현재 (아날로그) | CowTalk 도입 후 |
|---|---|
| 전염병 의심 → 시군 전화 취합에 수일 | 도내 52농장 발열 현황 **3초** (팅커벨 1문장) |
| 역학조사 — 서류·전화로 수일 | 접촉망(소 이동이력 기반) **30초** 식별 |
| 확산 규모 예측 불가 → 사후 살처분 | SEIR 시뮬레이션으로 **사전** 확산·살처분 범위 예측 |
| 농가 지도 — 방문·유선 개별 대응 | 농가·수의사·방역관·행정관이 **같은 데이터를 각자 관점**으로 |
| 구제역 1회 = 수십~수백억 보상·살처분 | 증상 발현 **전** 위내센서 조기감지로 차단 |

## 3. 무엇이 이미 만들어져 있는가 (2026-07-15 코드 실사 기준)

과장 없이, 구현·실DB 작동 확인된 것만 기재한다.

- **플랫폼 규모**: ~13만 LoC, DB 테이블 88개, API 라우트 63개, 테스트 70건
- **AI 비서 '팅커벨'**: Claude 기반, 도구 25개 자율 호출(조회 17 + 기록/액션 8), 음성 입출력, 방역 모드 자동 전환
- **거버넌스 (공공 도입의 핵심)**:
  - 4역할 RBAC — 농장주/수의사/방역관/행정관 도구 접근 차등
  - 전 AI 도구 호출 **감사 로그 자동 기록** (`tool_audit_log`)
  - **승인 게이트** — AI 제안 → 전문가(수의사) 승인 → 실행. 자동화도 승인 체계 우회 불가
  - 환각 방지 — 모든 수치는 DB 조회값만, 출처 기록 의무화
- **방역/역학**: 전국→시도→농장→개체 3단계 드릴다운, 146농장 실좌표 지도, SEIR 확산 시뮬레이션(실제 미분방정식), 접촉망 추적(실 이동이력), 역학조사·KAHIS 보고 DB 영속화
- **공공데이터 실연동**: 축산물이력제(EKAPE)·등급판정·경락가격 + 기상청 초단기실황(THI 열스트레스)
- **자기개선 루프**: 전문가 레이블 → 오탐 자동 라벨링 → 임계값·프롬프트 자기보정 (LLM이 스스로 재작성하지 않는 감사가능 구조)
- **번식 AI**: 6단계 칸반, 수정 적기, 발정동기화 4종 프로토콜 자동 일정, 젖소 정액 추천(내부데이터 기반 — 아래 로드맵 참조)

### 정직 고지 — 로드맵으로 분리하는 것
- 젖소 정액 추천 **정밀화**: 현재 카우톡 내부+등급 데이터 기반(신뢰도 표시). 종축개량협회 혈통 + DHI 검정 연동 시 환경변수 전환만으로 정밀도 자동 상승 → **도 차원 데이터 협조가 필요한 지점**
- 축사환경·사료 데이터 커넥터, 승인 게이트 대상 확대(현 1종 → 처방·방역조치)는 사업 기간 내 구축 항목

## 4. 사업 구조 (3단계)

| 단계 | 기간 | 내용 | 규모 |
|---|---|---|---|
| ① 실증 | 6개월 | 기존 52농장 + 공수의사 그룹 실증, 도 방역과 데이터 연계 | 시군 2~3곳 |
| ② 확산 | 1년 | 도내 낙농가 단계 확대, 젖소 혈통·DHI 연동(정액 추천 정밀화), 방역 행정 시스템(KAHIS) 공식 연계 | 낙농가 우선 |
| ③ 표준화 | 2년차~ | 경기도 전역 → 전국 표준 모델 수출, 도 축산 행정 대시보드 상시 운영 | 도 전역 |

## 5. 비용·편익 (기존 산정 — 경기도 실측으로 보정 전제)

전제: 경기 젖소 100,000두 · 목장 1,500개 · 두당 월 15,000원(센서+플랫폼)

- 1년차(구축 포함) **255억**, 2년차~ 매년 **180억**, 5년 누적 **975억**
- 농가 생산성 편익 **240억/년** (두당 24만원: 번식 10 + 질병 6 + 산유 5 + 노동 3)
- 기본 BCR **1.5**, 회수 **약 2.8년**
- 사회·환경 편익(육성우 감축 — 사육두수↓·생산량 유지): 사료 432억 + 분뇨 86억 + 탄소 108억 ≈ **626억/년**
- **통합 BCR ≈ 5.0** (보수 3.7 ~ 적극 5.5) + 방역 옵션가치(전염병 1회 차단 = 수백억)

> ⚠️ 육성우 감축률(40~50%)·탄소 가치·낙농 원단위는 경기도 실측 보정 필요. 상세는 ROI 시뮬레이터 엑셀 참조.

**행정용 한 줄: "연 180억은 보험료. 농가 생산성으로 3년 안에 회수하고, 전염병 한 번만 막으면 그 자체로 끝."**

## 6. 경기도에 드리는 요청

1. **시범사업 예산·행정 지정** — 시군 2~3곳 + 공수의사 실증
2. **데이터 연계 행정 협조** — KAHIS·이력제·도 방역 데이터, 종축개량협회 혈통·DHI(젖소 핵심)
3. **확산 로드맵 공동 수립** — 경기도 전역 → 전국 표준화 (표준을 만든 도가 주도권을 가진다)

## 7. 차별성 요약 (경쟁·대체재 대비)

- **smaXtec 대비**: 센서·알람은 smaXtec 그대로 신뢰(95%+ 재판단 안 함). CowTalk은 그 위에 공공데이터+AI 해석+4역할 행정 레이어 — 알람이 행동·행정으로 완결
- **범용 AI 챗봇 대비**: 팅커벨은 추측하지 않는다 — DB 조회값만, 출처 의무, 감사 로그, 역할별 권한, 승인 게이트 (공공 도입 요건 충족 구조)
- **아키텍처**: Palantir AIP의 핵심 패턴(온톨로지→도구→액션→승인→감사→자기개선)을 축산 도메인에 구현한 **축산형 AIP** — 성숙도 평가서 별첨
