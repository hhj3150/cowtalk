# CowTalk AI 플랫폼 사업 제안서 — 전라남도 (초안 v1, 2026-07-15)

> 제안명: **전남 축산 AI 플랫폼 사업** (가칭) — 한우 우선 실증, 전남 축산 전체로 확장
> 제안 골자: 전남의 강점(한우 대규모 사육)과 약점(고령화·방역 취약·역외 유통 의존)에
> CowTalk의 **한우 특화 기능(씨수소 추천·등급/경락 연동·방역 시뮬레이션)** 을 직결.
> 근거 문서: `cowtalk-aip-maturity-assessment-20260715.md` (구현 실사)

## 1. 한 줄 제안

**"전남 한우를 '더 적은 사람이, 더 건강하게, 더 비싸게' — 개량과 방역을 한 플랫폼으로."**

경기도 제안이 "젖소 + 디지털 행정"이라면, 전남 제안은 **"한우 + 개량·출하 소득 + 방역"** 이다.
CowTalk의 한우 기능 스택(씨수소 정보 API·등급판정·경락가격 실연동)은 **처음부터 한우를 위해 만들어져 지금 작동한다** — 전남이 가장 잘 쓸 수 있는 도(道)다.

## 2. 전남이 가진 문제

| 전남 현실 | CowTalk의 답 |
|---|---|
| 한우 사육 전국 최상위권 규모 — 그러나 개량·번식 관리는 농가 개별 역량에 의존 | 발정 알람 → 수정 적기 → **씨수소 추천(농촌진흥청 씨수소 API 실연동, 근교계수 6.25% 경고)** → 기록 → 임신감정 피드백까지 한 화면 완결 |
| 축산 농가 고령화 심각 — 새 시스템 학습 부담 | **팅커벨 음성 대화** — "423번 어때?" 한 마디면 끝. 앱 조작 학습 불필요 |
| 구제역·럼피스킨 등 재난형 가축전염병 — 발생 시 서남해안·도서 지역 역학조사 부담 | 전국→시도→농장→개체 드릴다운, 접촉망 30초 추적, **SEIR 확산 시뮬레이션으로 이동제한 시나리오 사전 비교** |
| 출하 시점·등급 판단이 감에 의존 | **등급판정·경락가격 실연동(EKAPE)** — 시세 기반 출하 의사결정 |
| 여름철 폭염 — 남부 지역 열스트레스 피해 | 기상청 실측 THI → **열스트레스 결정 카드** ("오늘 해야 할 일"로 자동 연결) |

## 3. 왜 CowTalk이 한우에 강한가 (구현 실사 기준)

경기(젖소) 맥락에서는 "정밀화 로드맵"이던 것이 전남(한우)에서는 **현재 작동 기능**이다.

- **한우 씨수소 추천**: 농촌진흥청 씨수소 정보 API(15101999) 연동 완료 — 전국 종모우 유전능력 기반 정액 추천 + 혈통 3대 근교계수 계산·경고. 동일 품종만 추천(교차 금지 가드)
- **이력제 완결**: 축산물이력제(12자리) 실시간 조회 실연동 — 한우는 이력제가 곧 자산 증명
- **등급·시세**: 등급판정 확인서 + 경락가격 시세 조회 도구가 팅커벨에 등록되어 대화로 즉답
- **번식 파이프라인**: 6단계 칸반(발정→수정→임신→분만), 수태율·공태일·분만간격 KPI, 발정동기화 4종 프로토콜 자동 일정
- **방역**: SEIR 확산 시뮬레이션(질병별 R0·잠복기·경제 손실), 역학조사·KAHIS 보고 영속화, 방역조치 CRUD(6유형×4상태)
- **거버넌스**: 4역할 RBAC + 전 도구 호출 감사 로그 + AI 제안→전문가 승인 게이트 — 공공 도입 요건을 갖춘 구조 (Palantir AIP형 아키텍처, 성숙도 평가서 별첨)

### 정직 고지
- 현재 CowTalk 네트워크 내 전남 소재 농장은 **8곳** — 경기(52곳)보다 기반이 작다. 그래서 전남 제안은 "이미 깔린 기반 확장"(경기형)이 아니라 **"도가 주도하는 신규 구축 시범사업"** 으로 설계한다.
- 위내센서(smaXtec)는 원래 젖소 중심 제품 — **한우 적용 실증(볼루스 정착·알람 정확도 검증)이 시범사업 1단계의 핵심 검증 항목**이다. 이 검증을 전남이 최초로 수행하면 전남이 "한우 디지털 표준"의 원산지가 된다.
- 사료·축사환경 데이터 커넥터는 스텁 상태 — 사업 기간 내 구축 항목.

## 4. 사업 구조 (3단계)

| 단계 | 기간 | 내용 | 검증 목표 |
|---|---|---|---|
| ① 한우 실증 | 1년 | 시군 1~2곳 한우 번식우 중심 시범 농가 구축(센서+플랫폼), 공수의사 연계 | 한우 발정탐지·질병 조기감지 정확도, 수태율 개선폭 실측 |
| ② 개량·출하 연계 | 1년 | 씨수소 추천 → 수정 → 송아지 → 등급 추적 루프 완성, 도 축산진흥 사업(우량 정액 지원 등)과 연계 | 근교 저감·등급 향상 실적 |
| ③ 도 방역망 통합 | 2년차~ | 도 방역 대시보드 상시 운영, KAHIS 연계, 재난형 전염병 대응 훈련(시뮬레이션 기반) | 역학조사 소요 시간 단축 실측 |

## 5. 기대효과 (전남 실측 기반 산정 전제)

> ⚠️ 아래는 산정 **구조**다. 전남 사육두수·농가수·시군 분포 실측치를 받아 계산식에 넣으면 확정된다 (경기도용 ROI 시뮬레이터 엑셀 3탭 구조 재사용).

- **농가 소득**: 번식 개선(수태율↑·공태일↓ → 송아지 회전율) + 등급 향상(개량 루프) + 질병 조기대응(폐사·치료비↓) — 한우는 두당 자산가치가 커서 **1두 폐사 방지 = 수백만원 직접 효과**
- **행정 효율**: 역학조사 수일 → 30초, 시군 취합 전화 → 팅커벨 1문장
- **방역 옵션가치**: 구제역·럼피스킨 1회 확산 차단 = 살처분·보상 수십~수백억 회피
- **고령화 대응**: 음성 AI로 디지털 소외 없이 전 연령 농가 사용 — 후계농 유입 매력 요소
- **탄소·환경**: 번식효율↑ → 불필요 사육 감축 → 사료·분뇨·탄소 저감 (경기 산정 구조 준용)

## 6. 전라남도에 드리는 요청

1. **한우 시범사업 지정·예산** — 시군 1~2곳, 번식우 중심 실증 (센서 보급 + 플랫폼 구독)
2. **데이터 연계 행정 협조** — KAHIS·이력제·도 방역 데이터 + 한우 개량 사업 데이터(지역 축협 검정 성적 등)
3. **공수의사·축협 연계 체계** — 승인 게이트(AI 제안→수의사 승인) 운영 주체 지정
4. **"한우 디지털 표준" 공동 브랜딩** — 전남 실증 결과를 전국 한우 주산지 표준으로 확산

## 7. 경기도 제안과의 관계 (병행 전략)

| | 경기도 | 전라남도 |
|---|---|---|
| 축종 | 젖소 중심 | **한우 중심** |
| 기반 | 기존 52농장 — 즉시 확장형 | 신규 구축 — 도 주도 시범형 |
| 핵심 가치 | 디지털 행정 대전환 + 방역 | **개량·출하 소득 + 방역 + 고령화 대응** |
| CowTalk 기능 적합도 | 정액 추천은 정밀화 로드맵 | **씨수소 추천이 현재 작동 (최대 강점)** |
| 검증 항목 | 광역 행정 통합 | 한우 센서 실증 (세계적으로도 선례 희소 → 선점 가치) |

두 사업은 경쟁이 아니라 상호 보강이다: 경기(젖소·행정)와 전남(한우·개량)이 각각 표준을 만들면
CowTalk 플랫폼은 국내 양대 축종을 모두 커버하는 **국가 축산 디지털 인프라**가 된다.
