# 통합 교육자료 — smaXtec 위내센서 + CowTalk AI

## 무엇인가

기존 smaXtec 위내센서 영문 교육자료(35장)에 **CowTalk AI 교육 파트 28장을 이어 붙인** 통합본.
총 **63장**. 원본의 디자인·번호·푸터 체계를 그대로 이어받는다.

| 파일 | 내용 |
|---|---|
| `smaxtec_cowtalk_en_training_with_ai.pptx` | 통합본 63장 (전 슬라이드 발표자 노트 포함) |
| `build_cowtalk_ai_slides.py` | 36~63장 생성 스크립트 — 원본 패키지에 직접 슬라이드를 써넣는다 |

## 원본 디자인 계승

새 슬라이드는 **새 테마·새 레이아웃을 만들지 않고** 원본의 `slideLayout1`을 그대로 참조한다.
따라서 폰트·마스터가 원본과 동일하다. 추출해서 재사용한 토큰:

| 토큰 | 값 |
|---|---|
| 배경 (light / dark) | `F5F3EA` / `0A1B17` |
| 본문 잉크 / 보조 | `10251F` / `66746F` |
| 아이브로우 틸 | `15A98C` |
| 액센트 그린 | `65D44A` |
| 코럴 · 블루 · 앰버 | `E96155` · `4C8DD9` · `F6B846` |
| 콜아웃 바 | `DFF4E8`, `roundRect` @ (0.75, 5.31, 11.83, 0.77) |
| 구분 패널 | `1BAF91` @ (10.83, 0, 2.5, 7.5) + 대각 원 5개 |
| 글자 크기 | 아이브로우 10.5 / 본문 16.5 / 제목 30 / 구분제목 40.5 / 구분번호 69 |

## 재생성

```bash
python3 -c "import zipfile; zipfile.ZipFile('원본.pptx').extractall('un')"
python3 build_cowtalk_ai_slides.py     # un/ 에 36~63장을 써넣고 pptx로 다시 압축
```

문구를 고칠 곳은 스크립트의 `SLIDES` 정의 한 곳이다.

## 검증 기록

- `validate.py --original` 통과 (스키마·관계·콘텐츠타입)
- 도형 화면 밖 이탈 0건 · 콜아웃 침범 0건 · 텍스트 넘침 0건
- 신규 28장 전부 발표자 노트 존재 · 플레이스홀더 잔여 0건

> ⚠️ 이 환경의 LibreOffice가 깨져 있어 PPTX 직접 렌더는 불가했다.
> 대신 생성한 슬라이드 XML을 **동일 좌표로 HTML 재현 후 Chromium 렌더**해 시각 검증했고,
> 폰트는 Calibri 메트릭 호환인 Carlito를 써서 줄바꿈·넘침을 판정했다.
> 파워포인트에서 한 번 열어 확인하는 것을 권한다.

## 내용 원칙

원본의 규율을 그대로 따랐다 — **"An alert is not a diagnosis"**의 CowTalk 판은
**"An AI answer is not a decision"**이다. 40장(무엇을 하지 않는가)과 45장(수의 섹션 서두)에
책임 경계를 명시했고, 근거 없는 답변을 실패로 규정했다.
