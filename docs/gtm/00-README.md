## 2. 대상별 "무엇을 가져갈 것인가" (발표자 치트시트)

발표는 **자료를 다 보여주는 것이 아니라 그 사람의 결재 문장 하나를 만들어주는 것**이다.
대상별로 그 문장이 다르다.

| 대상 | 그들이 결재해야 하는 문장 | 반드시 넣을 것 | 절대 넣지 말 것 |
|---|---|---|---|
| **지역정부(지자체)** | "우리 도(道)가 축산 디지털 전환을 **먼저** 했다" | 예산 규모·BCR·타 지자체 대비 선점·민원(악취) 완화 | 기술 스택, 코드 구조 |
| **중앙정부·국가기관** | "이 방식이 **전국 표준**이 될 수 있다" | 방역 지휘 체계 연계·KAHIS/이력제 정합·데이터 주권 | 개별 농가 수익 얘기만 |
| **전문가집단(수의사 등)** | "이건 나를 **대체**하는 게 아니라 **증폭**한다" | 감별진단 근거 노출·전문가 레이블 루프·책임 경계 | "AI가 진단합니다" 표현 |
| **해외정부** | "우리나라도 **주권을 지키며** 도입할 수 있다" | 소버린 배포·현지화 어댑터·ODA/KSP 연계 | 한국 특화 제도 세부 |
| **농가** | "내일 아침부터 뭘 하면 되는지 알겠다" | 알림→행동 3터치·두당 마진 변화 | ROI 수식, 정책 용어 |

## 3-1. 정책결정권자에게는 이 순서로 말한다

의사결정자는 기능을 사지 않는다. **당위성을 산다.** 네 칸으로 끝낸다.

| 칸 | 무엇을 말하나 | 이 자료의 근거 |
|---|---|---|
| **왜** | 지킬 사람이 없고, 질병은 늦게 발견되고, 감축 수단이 없다 — 셋 다 **보이지 않아서** 생긴다 | `10-one-pager.md` §왜 (전부 A등급 공표 통계) |
| **무엇을** | 소의 몸속 신호를 공공데이터·AI와 결합해 **역할별 행동**으로 바꾼다 | `01-introduction.md` |
| **어떻게** | 알람 → 판단 → 추천 → 행동 → 기록이 한 화면에서 끝난다 (4층 구조) | `01-introduction.md` §3 |
| **그래서** | 농가 소득 · 방역 · 탄소/환경 · 수의 인력 — **네 개 성과를 금액으로** | `08` · `09` |

## 4. 숫자를 말할 때의 규칙 (어기면 신뢰를 잃는다)

1. **규모 수치의 유일한 진실은 DB다.** 발표 직전 `GET /api/public/stats`로 확인하고 말한다.
   문서에 박힌 숫자는 스냅샷일 뿐이다.
2. **"약 200개 농장·1.1만 두"처럼 반올림해서 말하라.** 정밀한 숫자는 질문을 부르고,
   그 질문에 답 못하면 전체가 흔들린다.
3. **BCR·편익 수치는 반드시 "전제"를 함께 말한다.** ("경기 젖소 10만두 기준, 두당 월 1.5만원 전제")
4. **정확도는 출처를 붙인다.** 발정 탐지 95%+는 **smaXtec의 성능**이지 CowTalk이 측정한 값이 아니다.
5. **모르면 "아직 안 됐습니다, 로드맵입니다"라고 말한다.** 이게 가장 강력한 신뢰 자산이다.
6. **근거 등급을 구분해 발음한다.** "공표된 수치입니다"(A)와 "이건 가정입니다"(C)를 같은 톤으로 말하면,
   나중에 C 하나가 무너질 때 A까지 같이 무너진다. 등급표는 `08-impact-quantification.md` §1.
7. **BCR은 보수값 1.24를 기준으로 말한다.** 4.28을 먼저 말하면 나머지가 다 의심받는다.
9. **`14-cost-structure.md`는 외부에 배포하지 않는다.** 수입 단가와 D2O 손익이 들어 있다.
8. **위내센서가 모든 면에서 최고라고 말하지 않는다.** 발정 탐지는 가속도계가 강하다 — 이 정직함이 기술 신뢰를 만든다.
