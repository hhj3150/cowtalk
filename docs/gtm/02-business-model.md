# CowTalk 비즈니스 모델

> **한 문장**: 농가에게는 **구독**을 팔고, 지자체·국가에는 **인프라**를 팔고,
> 해외에는 **운영체제**를 판다. 그리고 그 위에 **데이터가 만드는 두 번째 매출**을 얹는다.
>
> ⚠️ 이 문서의 모든 금액은 **설계 기준선**이다. 실제 계약·심의 시 현지 실측으로 보정한다.
> 실제 코드에 구현된 가격은 §2-1의 Basic/Pro 뿐이다.

## 1. 수익 구조 — 6개의 축

```
                        ┌─────────────────────────────┐
                        │      CowTalk 플랫폼         │
                        └──────────────┬──────────────┘
        ┌──────────┬──────────┬────────┴────┬──────────┬──────────┐
        ▼          ▼          ▼             ▼          ▼          ▼
   ① 농가       ② 지자체    ③ 국가      ④ 거점      ⑤ 데이터   ⑥ 해외
     SaaS       라이선스    플랫폼      대동물병원   인텔리전스  수출
   (B2B)        (B2G)       (B2G)      (B2B2G)      (B2B)     (G2G)
   반복매출     반복+구축    대형구축    반복매출     고마진     로열티
```

| # | 수익축 | 과금 대상 | 과금 방식 | 성격 |
|---|---|---|---|---|
| ① | 농가 SaaS | 목장주 | 월 구독 (플랜 또는 두당) | 반복·소액·다수 |
| ② | 지자체 라이선스 | 시·도, 시군구 | 연간 (관내 두수 기반) | 반복·중액·예산연동 |
| ③ | 국가 플랫폼 | 중앙정부·검역기관 | 구축 + 연간 운영 | 대형·장기 |
| ④ | 거점 대동물병원 | 병원 (또는 지자체 대납) | 병원당 월 + 담당농가 연동 | 반복·신규 |
| ⑤ | 데이터 인텔리전스 | 사료·유업·보험·제약 | 리포트 구독 / API | 고마진·옵트인 |
| ⑥ | 해외 수출 | 해외 정부·현지 파트너 | 국가 라이선스 + 두당 로열티 | 대형·고마진 |

**핵심 설계 사상**: ①이 데이터를 만들고, ②③이 규모를 만들고, ⑤⑥이 마진을 만든다.
①만으로는 이익이 안 나고, ②③만으로는 데이터가 안 쌓인다. **셋이 같이 가야 한다.**

## 2. 축별 상세

### 2-1. 농가 SaaS (현재 구현된 유일한 가격표)

| 플랜 | 월 요금 | 대상 | 주요 기능 |
|---|---:|---|---|
| **Basic** | 50,000원 | 소규모 (≤100두) | 센서 실시간 모니터링, 발정·분만 알림(알림톡), 개체 건강 대시보드 |
| **Pro** | 100,000원 | 중형 (≤500두) | Basic + AI 번식 커맨드센터, 정액 추천 AI, 경제성 분석, 공공데이터 연동 |
| **Enterprise** | 별도 협의 | 다농장·수의사·기관 | Pro + 무제한 농장, 역할별 권한, API |

> 실제 구현: `packages/server/src/lib/toss-payments.ts` `SUBSCRIPTION_PLANS`

**두당 과금 모델 (지자체 사업용 — 권장 전환)**

플랜제는 개별 농가 자율 도입에 맞다. 그러나 **지자체 사업은 두당 과금이 맞다.**
예산 편성이 "관내 두수 × 단가"로 계산되기 때문이다.

| 항목 | 금액 | 비고 |
|---|---:|---|
| 센서 + 플랫폼 통합 구독 | **12,000원 / 두 / 월** | **현행 실단가.** 하드웨어 비용 별도 청구 없음 |
| 통신중계기 + 설치 | **5,000,000원 / 목장** (1회) | 삽입 시술·개체 기록·등록 포함, 최소 2회 방문 |

> ⚠️ **현행은 전액 목장 부담**이다. 보조금 없이 팔린 실적이라는 점이 이 사업의 최대 강점이다.
> 📎 원가 분해와 D2O 손익: [`14-cost-structure.md`](14-cost-structure.md)

**농가 부담 구조 (지자체 보조 시나리오)**

| 시나리오 | 지자체 | 농가 | 농가 실부담(100두 기준) |
|---|---:|---:|---:|
| 현행 (지원 없음) | 0% | **100%** | **120만원/월** |
| 확산기 (50% 매칭) | 50% | 50% | 60만원/월 |
| 자립기 (30% 지원) | 30% | 70% | 84만원/월 |

> **발표 시 강조**: 100두 농가 기준 월 120만원 = 연 1,440만원.
> 보수 편익(두당 8만원)이면 800만원, 기준 편익(두당 20.5만원)이면 2,047만원.
> **지금 이 가격을 농가가 자기 돈으로 내고 있다.**

### 2-2. 지자체 라이선스

| 규모 | 관내 두수 | 연간 라이선스 | 포함 |
|---|---|---:|---|
| 시군구 단위 | ~1만두 | 협의 (두당 요금에 통합 정산) | 행정·방역관 계정, 지역 대시보드, 월간 리포트 |
| 광역시도 단위 | 1~10만두 | 협의 | + 시도 통합 상황판, 확산 시뮬레이션, 정책 브리핑 |

> ⚠️ **이중 과금 금지**: 두당 SaaS를 지자체가 부담하는 구조에서
> 라이선스를 별도로 또 받으면 심의에서 반드시 걸린다. **통합 정산으로 설계한다.**

**경기도 기준 사업 규모** (검증된 표준 수치 — `docs/gyeonggi-deck/HANDOFF.md` §2)

| 항목 | 금액 |
|---|---:|
| 전제 | 젖소 100,000두 보급 · 약 1,430 목장 |
| 1년차 (구축 포함) | **약 215억** (중계기·설치 71억 + 구독 144억) |
| 2년차~ 매년 | **144억** |
| 5년 누적 | **약 791억** |

### 2-3. 국가 플랫폼

방역 조기감시망을 국가 인프라로 구축하는 사업.
**성격이 다르다** — 이건 SaaS가 아니라 **SI + 운영 위탁**이다.

| 구성 | 내용 |
|---|---|
| 구축 | 소버린 데이터센터 구축, KAHIS·이력제 연동, 전국 대시보드 |
| 운영 | 연간 운영·유지보수, SLA, 보안 감사 |
| 확산 | 시도별 온보딩, 교육 프로그램 |

> 이 축의 진짜 가치는 매출이 아니라 **레퍼런스**다.
> "대한민국 정부가 쓰는 시스템"이 해외 수출의 최강 세일즈 포인트가 된다.

### 2-4. 거점 대동물병원 (신규 축 — 상세는 `05-vet-hub-hospital.md`)

| 과금 | 금액(기준선) | 비고 |
|---|---:|---|
| 병원 기본 | 300,000원/월 | 케이스 큐, 왕진 스케줄, 감별진단, 처방·휴약 관리 |
| 담당 농가 연동 | 20,000원/농가/월 | 원격 트리아지 대상 농가 수 |

**결제 주체가 핵심이다.** 대동물병원은 지불 여력이 크지 않다.
그래서 **정부 시범사업 예산이 병원 대신 결제하는 구조**로 설계한다.
→ 병원은 무료로 도구를 얻고, 정부는 "수의사 1인당 담당 가능 농가 수"라는 정책 지표를 얻는다.

### 2-5. 데이터 인텔리전스 (가장 마진이 높고, 가장 조심해야 할 축)

**팔 수 있는 것 (익명화·집계만)**

| 상품 | 고객 | 가치 |
|---|---|---|
| 지역 질병 발생 동향 리포트 | 동물약품·제약 | 수요 예측, 영업 타게팅 |
| 사료·번식 성적 벤치마크 | 사료회사 | 제품 효과 검증, R&D |
| 산유·유성분 지역 추이 | 유업체 | 원유 수급 예측 |
| 개체 위험도 기반 언더라이팅 지표 | 가축보험 | 요율 산정, 손해율 개선 |
| 정책 효과 분석 | 연구기관·정부 | 사업 평가 |

**절대 팔지 않는 것**
- 개체 식별 가능 데이터
- 농가 식별 정보 (이름·연락처·정확한 위치)
- 진료·처방 원본 기록

**3중 조건**: ① 농가 옵트인 ② 익명화 ③ 집계 단위 (최소 N개 농가 이상)
→ 하나라도 빠지면 판매 불가. 이 원칙을 어기면 **①~④ 전부가 무너진다.**

### 2-6. 해외 수출 (상세는 `06-export-playbook.md`)

| 모델 | 구조 | 적합 |
|---|---|---|
| **A. 국가 라이선스** | 국가 단위 연간 고정 + 소버린 인스턴스 구축비 | 중동 (국부펀드·정부 주도) |
| **B. 두당 로열티** | 현지 파트너가 운영, 두당 로열티 | 동남아 (민간 확산형) |
| **C. ODA/KSP 연계** | 공적개발원조 사업으로 구축, 이후 운영 전환 | 동남아 초기 진입 |
| **D. 화이트라벨** | 현지 브랜드로 공급, 코어는 D2O | 대형 현지 기업 존재 시 |

> **권장 진입 순서**: C(무상 파일럿) → A/B(유상 확산) → D(대규모 시)

**AI 추론 비용 관리 — 이 사업의 숨은 변수**

LLM 호출 비용은 두수에 비례해 늘어난다. 이미 구조적으로 방어하고 있다.
- **프롬프트 캐싱** (시스템 프롬프트 + 도구 정의) → 반복 호출 비용 절감
- **모델 이원화**: 대화·추출은 경량 모델, 깊은 분석만 고성능 모델
- **추론 예산 스위치**: 환경변수로 즉시 조절 가능 (배포 없이)
- **룰 엔진 폴백**: AI 없이도 기본 기능 성립 → 비용 상한 통제 가능

## 4. ROI — 지자체에 제출할 숫자

**전제**: 경기 젖소 100,000두 보급 · 약 1,430 목장 · 두당 월 **12,000원**(현행) · 중계기·설치 500만/목장

### 4-1. 비용

| 구분 | 금액 |
|---|---:|
| 1년차 (구축 포함) | 약 215억 |
| 2년차~ 매년 | **144억** |
| 5년 누적 | 약 791억 |

### 4-2. 농가 생산성 편익 (두당 24만원/년)

| 항목 | 두당/년 |
|---|---:|
| 번식효율 개선 (공태일 단축) | 100,000원 |
| 질병 조기대응 | 60,000원 |
| 산유량 향상 | 50,000원 |
| 노동 절감 | 30,000원 |
| **합계** | **240,000원** |

→ 100,000두 = **연 240억**

### 4-3. 사회·환경 편익 — "적게 키우고 더 잘 짠다"

번식효율↑ + 생애수명 연장 → **육성우(후보축) 감축**.
**핵심: 사육두수는 줄어도 우유 총생산량은 유지된다.**

| 항목 (육성우 36,000두 감축 기준) | 연간 효과 |
|---|---:|
| 사료비 절감 | 432억 |
| 분뇨 배출 감소 28.8만톤 → 처리비 | 86억 |
| 탄소 저감 10.8만톤 CO₂eq → 사회적 가치 | 108억 |
| **소계** | **약 626억/년** |

### 4-4. 통합 ROI

| 지표 | 값 |
|---|---|
| 연간 총편익 | 178.0억(보수) ~ 616.3억(적극) |
| 연간 비용 (구독) | 144억 |
| **BCR (보수 / 기준 / 적극)** | **1.24 / 3.04 / 4.28** |
| 개체 편익만 본 BCR (보수) | 0.56 |
| 회수 기간 (자가도입 모델) | 약 1.9년 |
| 참고 | 상세 산정: [`08-impact-quantification.md`](08-impact-quantification.md) |

> **행정용 한 줄**:
> "연 144억은 비용이 아니라 **보험료**입니다. 농가 생산성으로 3년 안에 회수하고,
> 사육두수를 줄이면서 생산량은 유지해 사료·분뇨·탄소를 동시에 절감하고,
> **전염병을 한 번만 막으면 그 자체로 끝납니다.**"

> ⚠️ **정직성 고지**: 육성우 감축률(40~50%), 탄소 사회적가치 단가, 낙농 원단위는
> 문헌·추정 기반이다. **해당 지자체 실측으로 보정 필요**함을 발표에서 반드시 밝힌다.
> 이 고지가 오히려 숫자 전체의 신뢰도를 올린다.

## 5. 가격 전략 — 시장별 차등

| 시장 | 전략 | 이유 |
|---|---|---|
| 한국 농가 | 침투가 (낮게 시작) | 도입 저항이 최대 장벽. 규모부터 만든다 |
| 한국 지자체 | 가치가 (BCR 근거) | 예산은 편익 근거로 움직인다 |
| 선진 낙농국 | 프리미엄 (AI 레이어만) | 센서는 이미 있음. 애드온으로 고가 |
| 동남아 | 저가·ODA 연계 | 지불 여력 제약, 공적자금 활용 |
| 중동 | 프리미엄 국가계약 | 예산 제약 낮음, 통째로 원함 |

**절대 하지 말 것**: 한국 가격을 그대로 해외에 제시하는 것.
동남아에는 비싸고 중동에는 싸다. **둘 다 계약을 놓친다.**

## 6. 성장 지표 (KPI) — 무엇을 보고 경영할 것인가

| 단계 | 핵심 지표 | 목표 감각 |
|---|---|---|
| **도입** | 연결 두수, 농가 수, 센서 가동률 | 가동률 95%+ 유지 |
| **정착** | **조치 기록률** (알림 → 실제 행동 비율) | 이 지표가 낮으면 제품이 실패한 것 |
| **가치** | 두당 일 마진 변화, 공태일, 수태율 | 파일럿 전후 비교 |
| **확산** | 농가 유지율(retention), NPS | 유지율 90%+ |
| **공공** | 조기감지 리드타임, 방역 대응 시간 | 신고 대비 며칠 빨랐나 |

> **가장 중요한 단 하나**: **조치 기록률.**
> 알림을 100개 보내고 아무도 행동하지 않으면 그 제품은 실패다.
> CowTalk의 존재 이유가 "알람 → 행동"이므로, 이것이 제품의 생명선이다.

## 7. 경쟁·대체재 포지셔닝

| 대체재 | 그들의 강점 | CowTalk의 답 |
|---|---|---|
| 센서 단독 (smaXtec 등) | 검증된 정확도 | **우리는 그 위층이다. 경쟁 아님** |
| 농장관리 SW (ERP형) | 익숙함, 저렴 | 사람이 입력해야 산다. 우리는 센서가 넣는다 |
| 국가 방역 시스템 | 법적 권위 | 신고 이전을 본다. 앞단에 붙는다 |
| 대기업 스마트팜 플랫폼 | 자본·영업력 | 축우 **몸속 데이터 + 4역할 + 방역**은 없다 |
| 아무것도 안 함 | 비용 0 | 사람이 사라지고 있다. 그게 비용이다 |
