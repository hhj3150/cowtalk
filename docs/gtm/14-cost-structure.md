# 원가 구조와 손익 모델
## 현행 실제 구조 기준 — 두당 12,000원 안에 무엇이 들어 있나

> **이 문서는 추정이 아니라 현행 실거래 조건에서 출발한다.**
>
> | 현행 조건 (2026-08) | 값 |
> |---|---|
> | 밸류체인 | smaXtec → **코리아제네틱스(수입)** → **D2O(판매)** → 목장 |
> | 목장 수취 구독료 | **12,000원 / 두 / 월** |
> | 수입사(코리아제네틱스) 지급 | **7,700원 / 두 / 월** |
> | 통신중계기 + 설치비 | **500만원 / 목장** (삽입·개체기록·등록 포함, **최소 2회 방문**) |
> | 하드웨어 별도 청구 | **없음** — 정기구독료에 전부 포함 |
> | 지금까지의 지불 주체 | **전액 목장 부담** (지자체 보조 없이) |
> | 데이터센터 운영 | **업체 미정 — 확보 필요** |
> | 데이터 주권 귀속 | **미해결** |
>
> ⚠️ D2O 내부 운영비(§2-2)는 아직 실적이 아니라 **추정(등급 C)**이다. 실비가 나오면 교체한다.

## 0. 결론 먼저 — 세 문장

1. **구독 총이익률은 35.8%다.** 12,000원 중 7,700원이 수입사로 나가고 4,300원이 남는다.
2. **운영비를 빼면 두당 월 약 1,450원(12.1%)이 남는다.** 얇다. 규모가 없으면 고정비를 못 덮는다.
3. **그런데 지금까지 전액 목장이 자기 돈으로 냈다.** 이건 약점이 아니라 **가장 강력한 증거**다 —
   **보조금 없이 팔린 제품**이라는 레퍼런스는 지자체 심의에서 무엇보다 세다.

## 1. 밸류체인 — 12,000원이 어디로 가나

```
   목장  ──── 12,000원/두/월 ────▶  D2O (판매)
                                      │
                                      │ 7,700원 (64.2%)
                                      ▼
                            코리아제네틱스 (수입)
                                      │
                                      │ 추정 6,220원
                                      ▼
                                  smaXtec (제조)
```

### 1-1. 각 단계의 몫 (추정 포함)

| 주체 | 원/두/월 | 비중 | 근거 |
|---|---:|---:|---|
| **smaXtec** (제조·데이터 해석) | 약 6,220 <sub>추정</sub> | 51.8% | 공개 참고시세 **$2.49/두/월**(≈3,360원) + 센서 $89(≈12만원) ÷ 42개월(≈2,860원) |
| **코리아제네틱스** (수입·통관·유통) | 약 1,480 <sub>추정</sub> | 12.3% | 7,700 − 6,220. 수입 마진 약 **24%** |
| **D2O** (플랫폼·판매·운영) | **4,300** | **35.8%** | 12,000 − 7,700 (**실거래**) |
| **목장 지불** | **12,000** | 100% | **실거래** |

> **읽는 법**: smaXtec 몫과 KG 마진은 **우리 추정**이다. 공개 참고시세에서 역산했다.
> 실제 수입 원가는 코리아제네틱스만 안다. **협상하려면 이 숫자를 확인하는 것이 첫 단계다.**
>
> 다만 추정이 맞다면 **KG의 수입 마진 24%는 통상적인 수준**이고,
> 문제는 KG의 마진이 아니라 **smaXtec 몫이 전체의 절반**이라는 것이다.
> **원가 협상의 상대는 KG가 아니라 smaXtec이다.**

### 2-2. 설치 부문 (1회 매출)

| 항목 | 금액 | 비고 |
|---|---:|---|
| 목장 수취 | **5,000,000원 / 목장** | 실거래 |
| 포함 항목 | 통신중계기 HW · 시공 · **개체 삽입 시술** · 개체 기록 · 시스템 등록 | |

| 항목 | 추정 | 비고 |
|---|---:|---|
| 통신중계기 HW + 시공 | 2,000,000~3,000,000원 | 수입 원가 확인 필요 |
| 방문 2회 (2인 × 2일 + 차량) | 1,000,000~1,500,000원 | 거리에 따라 변동 |
| 개체 삽입 · 기록 · 등록 | 인건비에 포함 | 100두 기준 1일 |
| **추정 원가 합계** | **3,000,000~4,500,000원** | |
| **추정 마진** | **500,000~2,000,000원** | |

> **설치 부문은 이익 센터가 아니라 원가 회수 구조로 봐야 한다.**
> 그리고 **최소 2회 방문**이 구조적 부담이다 — 거리가 멀수록 마진이 사라진다.
>
> **개선 과제 3가지**
> 1. **1회 방문으로 줄이기** — 사전 등록(원격 입력) + 현장은 설치·삽입만
> 2. **권역 단위 일괄 설치** — 인접 농가를 묶어 방문당 여러 목장 처리
> 3. **중계기 공유** — 인접 농가 공동 사용으로 목장당 500만원 부담 완화

## 3. 손익분기 — 몇 두를 모아야 하나

**기여이익 1,450원/두/월 = 연 17,400원/두**

| 연 고정비 (개발·영업·관리) | 손익분기 두수 |
|---:|---:|
| 3억 | 약 **17,200두** |
| 5억 | 약 **28,700두** |
| 10억 | 약 **57,500두** |
| 15억 | 약 **86,200두** |

> ⚠️ **이것이 이 사업의 가장 냉정한 숫자다.**
> 경기 젖소 전체가 150,364두다. 고정비 15억이면 **경기도의 57%를 깔아야 손익분기**다.
>
> **결론: 현행 단가 구조로는 구독 매출만으로 사업이 성립하기 어렵다.**
> 아래 §4의 세 가지 출구가 선택이 아니라 필수인 이유다.

## 4. 세 개의 출구 — 이익을 만드는 실제 경로

### 출구 ① 원가를 내린다 (수입 단가 협상)

| 레버 | 효과 | 비고 |
|---|---|---|
| **smaXtec 볼륨 단가 인하 10%** | 두당 월 **약 620원** 절감 | 협상 상대는 smaXtec. KG를 통해 또는 직접 |
| **수입 구조 재설계** | KG 마진 구간 재협상 | 관계 훼손 주의 — **볼륨 성장을 조건으로** |
| **생산수명 연장** | 상각 기간 42→54개월 시 **약 630원** 절감 | **제품이 잘 되면 자동으로 온다** |

> 💡 **자기강화 구조**: CowTalk이 하는 일이 질병 조기대응과 번식 성적 개선이다.
> 그러면 도태가 늦어지고 **센서 상각 기간이 늘어 원가가 내려간다.**
> 국내 젖소는 대부분 3산을 못 채우고 도태된다 — **여기를 개선하면 우리 원가가 개선된다.**

### 출구 ② 지불 주체를 바꾼다 (전액 목장 부담 → 지자체 매칭)

지금까지 **전액 목장이 부담**했다. 이건 두 가지를 동시에 뜻한다.

| 뜻 | 함의 |
|---|---|
| ✅ **보조금 없이 팔렸다** | **가장 강력한 시장 검증.** 지자체 심의에서 이보다 센 증거가 없다 |
| ⚠️ 확산 속도의 상한 | 낙농은 지금 역마진이다. 자부담만으로는 규모가 안 나온다 |

> **전략**: 자부담 실적을 **근거로 제시**하고, 지자체 매칭으로 **확산 속도를 올린다.**
> 가격을 낮추는 게 아니라 **지불 주체를 나누는 것**이다 — 단가는 지키고 농가 부담만 줄인다.

### 출구 ③ 두당 요금 밖에서 번다 (한계원가 ≈ 0)

| 수익축 | 성격 | 추가 원가 |
|---|---|---|
| **플랫폼 구축·운영 (SI)** | 지자체·국가가 CowTalk 기반 플랫폼을 구축 | **§5 참조 — 별도 계약** |
| **거점 대동물병원** | 병원 월 30만 + 담당농가 월 2만 | 거의 없음 |
| **조합·유업체 리포트** | 품질·수급 집계 | 거의 없음 |
| **데이터 인텔리전스** | 옵트인·익명·집계 | 거의 없음 |
| **해외 라이선스** | 국가 단위 | 소버린 인스턴스 구축비 |

> **핵심**: 구독은 **원가를 덮는 사업**이고, 이 축들이 **이익을 만드는 사업**이다.
> 이미 수집·저장하는 데이터를 다른 관점으로 파는 것이라 한계원가가 거의 없다.

## 5. 플랫폼 구축·운영비 — 지금까지 값을 매기지 않았던 것

지자체·국가가 **CowTalk을 기반으로 자기 플랫폼을 만드는** 사업은
구독과 성격이 완전히 다르다. **이건 SI 매출이고, 별도로 값을 매겨야 한다.**

### 5-1. 구축비 (1회)

| 항목 | 내용 | 규모 감각 |
|---|---|---|
| 요구사항 정의 · 설계 | 지자체 업무 프로세스 분석, 권한 체계 설계 | |
| **공공데이터 연계 개발** | KAHIS · 이력제 · 도 방역 · 기상 커넥터 | 커넥터당 개발 공수 |
| **행정 워크플로 개발** | 보고 양식, 결재선, 통계 리포트 | 지자체마다 다름 |
| 소버린 인스턴스 구축 | DB · 연산 · 백업 · DR · 보안 | |
| 데이터 이관 · 초기 적재 | 기존 대장·이력 데이터 | |
| 교육 · 매뉴얼 | 5트랙 커리큘럼 | [`04`](04-education-curriculum.md) |
| **합계** | **인월(M/M) 기반 산정** | 규모에 따라 협의 |

### 5-2. 운영비 (연간)

| 항목 | 내용 |
|---|---|
| 인프라 운영 | 데이터센터 · 클라우드 · 회선 · 백업 |
| 유지보수 | 장애 대응 · 패치 · 보안 업데이트 |
| 기능 개선 | 연간 개선 요구 반영 |
| **SLA 대응** | 가용성 보장 · 24/7 지원 여부에 따라 차등 |
| 정기 교육 | 인사이동 대응 |

> ⚠️ **반드시 지켜야 할 원칙**:
> **구독료(두당 12,000원)와 플랫폼 구축·운영비를 이중으로 받지 않는다.**
> 지자체 심의에서 가장 먼저 걸리는 지점이다.
> **구독 = 농가 서비스 / 구축·운영 = 행정 시스템**으로 성격을 명확히 나눠 계약한다.

## 6. 데이터 주권 — 지금 반드시 정해야 할 것

> **현재 상태: 미해결.** 데이터센터 운영 업체도 아직 없다.
> **이건 기술 과제가 아니라 계약·거버넌스 과제이고, 늦게 정할수록 비싸진다.**

### 6-1. 왜 지금 정해야 하나

| 이유 | 설명 |
|---|---|
| **지자체·국가 계약의 전제** | "데이터가 어디 쌓이나"에 답 못 하면 심의를 통과하지 못한다 |
| **해외 수출의 전제** | 대부분의 국가가 데이터 현지화를 요구한다 |
| **농가 신뢰의 전제** | "내 목장 데이터를 회사가 가져간다"고 느끼면 도입이 멈춘다 |
| **파트너 협상의 전제** | 나중에 정하면 상대의 협상력이 커진 뒤가 된다 |

### 6-2. 세 가지 안

| 안 | 구조 | 장점 | 단점 |
|---|---|---|---|
| **A. D2O 보관** | D2O가 계약한 IDC/클라우드 | 빠름 · 통제 쉬움 | 공공 심의 통과 어려움 · "민간이 국가 방역 데이터 보유" 논란 |
| **B. 공공 인프라 위탁** | 지자체·공공기관 클라우드에 적재 | **심의 통과 유리** · 신뢰 확보 | 조달 절차 · 유연성 저하 · 비용 협의 필요 |
| **C. 합작 SPC** | 데이터센터 운영 법인을 별도 설립 | 중립성 · 수익 공유 · **수출 시 복제 가능** | 설립 비용 · 지분 협상 |

> **권장**: **국내는 B(공공 위탁)** 로 시작하고, 규모가 커지면 **C(합작 SPC)** 로 전환.
> **해외는 처음부터 C 구조**로 국가별 소버린 인스턴스를 만든다.
> 어느 경우든 **SW 운영 주체(D2O)와 데이터 보관 주체를 분리**하는 것이 핵심이다.
> 📎 [`03-partner-architecture.md`](03-partner-architecture.md) §4 데이터 소유권 4계층

### 6-3. 데이터센터 업체 선정 시 확인할 것

- [ ] 국내 리전 · 물리적 위치 명시
- [ ] 시계열 대용량 처리 (두당 월 9,000~17,000행 × 두수)
- [ ] 백업 · 재해복구(DR) SLA
- [ ] **감사 로그 보존 기간과 열람 권한**
- [ ] 공공 조달 등록 여부 (지자체 계약 시 필수)
- [ ] 계약 종료 시 **데이터 반환 · 파기 절차**
- [ ] 두당 단가 구조 (두수 증가 시 체감 구조인가)

| 10,000원 | 2,300 | (550) | 적자 | 1.48 |
| **12,000원** | **4,300** | **1,450** | **12.1%** | **1.24** |
| 13,000원 | 5,300 | 2,450 | 18.8% | 1.14 |
| 15,000원 | 7,300 | 4,450 | 29.7% | 0.99 |

> **현행 12,000원은 농가 쪽에서 보면 BCR 1.24로 방어된다** — 나쁘지 않은 가격이다.
> 문제는 사업자 이익률 12.1%가 얇다는 것이고,
> **그 원인은 가격이 낮아서가 아니라 원가(7,700원)가 높아서다.**
>
> **가격을 올리는 대신 원가를 내리는 것이 정답이다.**
> 12,000원을 유지하면서 수입 단가를 1,000원 낮추면 이익률이 **20.4%**가 된다.
