# 탄소 저감 · 기후변화 대응 · 환경부담 저감
## 축산 정책이자 환경 정책이라는 것을 숫자로

> **핵심 명제**: 축산 온실가스를 줄이는 방법은 두 가지뿐이다.
> **① 한 마리가 덜 배출하게 하거나, ② 마리 수를 줄이거나.**
> 지금까지의 정책은 대부분 ①(저메탄 사료, 분뇨처리 기술)이었다.
> CowTalk은 **②를 생산량 손실 없이** 가능하게 한다.
> **적게 키우고 더 잘 짠다** — 이것이 이 플랫폼의 환경 명제다.

---

## 1. 왜 — 정책이 이미 요구하고 있다

| 정책 목표 | 내용 | 등급 |
|---|---|:---:|
| **2030 NDC** | 2018년 대비 국가 온실가스 **40% 감축** | A |
| **농축수산 부문** | 2018년 2,470만톤 기준 **25.9% 감축** (21.6%에서 상향) | A |
| **축산 분야** | 2030년까지 축산 온실가스 **30% 감축** (농식품부) | A |

**그런데 축산은 감축 수단이 구조적으로 부족하다.**
제조업은 연료를 바꾸면 되고 발전은 전원을 바꾸면 된다. 축산은 **생물이 대사하며 내는 메탄**이다.
저메탄 사료·분뇨처리 고도화가 있지만 단위당 저감이고 도입 비용이 든다.

> **여기서 CowTalk의 자리가 생긴다.**
> 번식효율을 올리고 생애수명을 늘리면 **같은 우유를 더 적은 소로** 생산한다.
> 이건 총량 감축이고, 농가가 **돈을 벌면서** 하는 감축이다.
> 감축을 위해 농가에 비용을 부담시키지 않는 거의 유일한 수단이다.

## 2. 무엇을 — 축산의 환경부담 실측

### 2-1. 온실가스 (등급 A + 유도)

| 항목 | 값 |
|---|---|
| 축산 분야 총배출 (2018) | **941만톤 CO₂eq** (장내발효 447 + 분뇨처리 494) |
| 장내발효 중 소 비중 | **91.7%** (한·육우 67.8% + 젖소 23.9%) |
| 젖소 기여 | 장내발효 22.2% · 분뇨처리 15.1% |
| **젖소 부문 소계 (유도)** | **약 173.8만톤 CO₂eq / 년** |
| **젖소 두당 (유도)** | **약 4.2톤 CO₂eq / 두 / 년** |

```
유도 과정 (공개)
  젖소 장내발효   447만톤 × 22.2% =  99.2만톤
  젖소 분뇨처리   494만톤 × 15.1% =  74.6만톤
  젖소 소계                        173.8만톤 CO₂eq
  ÷ 당시 젖소 사육두수 약 41만두
  = 두당 약 4.2톤 CO₂eq / 년
```

> **비교 감각**: 승용차 1대 연간 배출이 대략 2톤 CO₂eq다.
> **젖소 한 마리는 승용차 두 대 몫**을 배출한다. 이 문장 하나가 정책 담당자에게 규모감을 준다.

### 2-2. 가축분뇨 (등급 A)

| 항목 | 값 |
|---|---|
| 전국 가축분뇨 발생량 | **연 5,073만톤** |
| 축종별 — 돼지 | 1,921만톤 (37.9%) |
| 축종별 — 한·육우 | 1,735만톤 (34.2%) |
| 축종별 — 가금 | 18.8% |
| **축종별 — 젖소** | **9.1%** (약 462만톤) |
| 처리 방식 | 퇴비 **75.3%** · 액비 **11.7%** · 정화 **13%** |
| 젖소 배출원단위 | 약 **28kg/두/일** (≈10.2톤/두/년) |

> **주목할 지점**: 분뇨의 **87%가 퇴비·액비로 농경지에 살포**된다.
> 그리고 과거 조사에서 **악취 민원의 52%가 토양 살포에서 발생**했다.
> 즉 **분뇨 총량을 줄이는 것이 악취 민원을 줄이는 가장 직접적인 경로**다.
> 지자체 담당자에게는 탄소보다 이 문장이 더 크게 들린다.

## 3. 어떻게 — 세 개의 감축 경로

```
┌───────────────────────────────────────────────────────────────┐
│  경로 ①  사육두수 최적화 — 지금 바로 작동 (구현 완료)          │
│  번식효율↑ · 생애수명↑ → 대체 후보축(육성우) 수요↓            │
│  → 사육두수↓ · 생산량 유지 → 사료·분뇨·메탄 동시 감소          │
├───────────────────────────────────────────────────────────────┤
│  경로 ②  개체 건강 최적화 — 지금 바로 작동 (구현 완료)         │
│  질병 조기대응 → 폐사·도태↓ → 대체 두수↓                      │
│  케토시스·산독증 관리 → 사료효율↑ → 단위생산당 배출↓          │
├───────────────────────────────────────────────────────────────┤
│  경로 ③  축산환경 모듈 — 로드맵 (소유자 전문 도메인)           │
│  HBP 시스템 기반 축사 내 발효 → 악취·환경부하 저감            │
│  → 퇴비·토양 순환으로 경축순환 완성                            │
└───────────────────────────────────────────────────────────────┘
```

### 3-1. 경로 ① — 사육두수 최적화가 왜 감축인가

낙농의 후보축(육성우)은 **생산을 하지 않으면서 먹고 배출한다.**
분만해 착유를 시작하기까지 약 2년, 그동안 사료를 먹고 메탄을 내고 분뇨를 낸다.

후보축을 얼마나 키워야 하는지는 **경산우가 얼마나 오래, 얼마나 잘 번식하느냐**로 결정된다.

```
공태일 길다 · 수태율 낮다 · 질병으로 일찍 도태된다
   → 대체할 소를 더 많이 키워야 한다
   → 육성우 사육두수 증가
   → 사료 · 분뇨 · 메탄 증가

공태일 짧다 · 수태율 높다 · 오래 산다
   → 대체 수요 감소
   → 육성우 감축
   → 사료 · 분뇨 · 메탄 감소   ← 생산량은 그대로
```

> **이것이 "적게 키우고 더 잘 짠다"의 기전이다.**
> 그리고 이 기전의 앞단은 전부 CowTalk이 이미 하고 있는 일이다 —
> 발정 탐지, 수정 적기, 정액 추천, 질병 조기감지, 치료 결과 추적.
> **환경 성과를 위해 새로 할 일이 없다. 번식·건강을 잘하면 환경이 따라온다.**

### 3-2. 경로 ③ — HBP 시스템 (로드맵 · 차별화 축)

> ⚠️ 공식 명칭: **휴머스(HUMUS)를 활용한 HBP 시스템(Humus Bedded Pack barn)**
> 프레이밍: **HBP 시스템 기반 축산환경관리 및 경축순환모델 확립**
> 적용 축종: 낙농 · 비육우 · 육계 · 양돈

| 단계 | 내용 |
|---|---|
| 1 | 축사 깔짚을 휴머스 기반으로 운용 |
| 2 | 분뇨가 **축사 내에서 발효** — 별도 처리시설로 옮기기 전에 분해 시작 |
| 3 | 악취·환경부하 저감 — 민원의 근본 원인에 접근 |
| 4 | 퇴비·토양 순환으로 **경축순환 완성** |

**CowTalk과의 결합점**: 축사 환경 데이터(온습도·발효 상태)와 개체 데이터(체온·활동량·유량)를
한 화면에서 보면, **환경 관리가 생산성에 미치는 영향을 실측**할 수 있다.
지금까지 축산환경은 "비용"이었지만, 데이터가 붙으면 **투자 대비 효과를 증명할 수 있는 영역**이 된다.

> **정책 제안 시 활용**: 경기도 제안서의 차별화 축.
> "환경 규제 준수"가 아니라 **"환경 관리로 생산성을 올린다"**는 프레임 전환.

## 4. 그래서 무엇을 얻나 — 금액 환산

**전제**: 경기 젖소 100,000두 보급(약 67%) · 대상 육성우 53,600두

| 감축률 | 감축 두수 | 사료 절감 | 분뇨 감소 | 처리비 절감 | 탄소 저감 | 탄소 가치<br><sub>시장 1만/중간 3만/사회 10만</sub> |
|---:|---:|---:|---:|---:|---:|---:|
| **15%** 보수 | 8,040두 | 96.5억 | 6.4만톤 | 19.3억 | 2.4만톤 | 2.4 / 7.2 / 24.1억 |
| **30%** 기준 | 16,080두 | 193.0억 | 12.9만톤 | 38.6억 | 4.8만톤 | 4.8 / 14.5 / 48.2억 |
| **45%** 적극 | 24,120두 | 289.4억 | 19.3만톤 | 57.9억 | 7.2만톤 | 7.2 / 21.7 / 72.4억 |

### 4-1. 정책 목표 대비 기여도 — 이 표가 정책결정권자에게 가장 크게 들린다

```
경기 젖소 150,364두 × 4.2톤 CO₂eq = 약 63.2만톤 / 년
축산 2030 감축목표 30%              → 경기 젖소 감축 필요량 약 19.0만톤
```

| 감축률 | 프로그램 탄소 저감 | **경기 젖소 2030 감축목표 대비** |
|---:|---:|---:|
| 15% 보수 | 2.4만톤 | **약 13%** |
| 30% 기준 | 4.8만톤 | **약 25%** |
| 45% 적극 | 7.2만톤 | **약 38%** |

> **발표용 한 줄**:
> "경기도 젖소 부문 2030 온실가스 감축 목표의 **13~38%를, 사육두수 최적화 하나로** 달성합니다.
> 농가에 추가 비용을 부담시키지 않고, 오히려 **사료비를 96억에서 289억까지 줄이면서** 하는 감축입니다."

### 4-2. 환경부담 저감 — 탄소 외의 세 가지

| 항목 | 효과 (30% 기준) | 왜 중요한가 |
|---|---|---|
| **분뇨 총량** | 연 **12.9만톤 감소** | 87%가 농경지 살포 → **악취 민원 직접 감소** |
| **질소·인 부하** | 분뇨 감소에 비례 | 수질 오염 부하 저감. 살포 가능 농지 제약 완화 |
| **사료 자원** | 연 **193억 절감** | 수입 조사료·곡물 의존도 감소 → **식량안보에도 기여** |

> **지자체 담당자에게는 탄소보다 악취가 급하다.** 순서를 바꿔 말한다 —
> "분뇨가 연 12.9만톤 줄어듭니다. 그 87%가 농경지에 뿌려지던 것이고,
> 악취 민원의 절반이 거기서 나옵니다. **탄소는 그 다음 이야기입니다.**"

## 5. 이 주장의 약한 곳 (먼저 말해야 방어된다)

| 약점 | 정직한 설명 |
|---|---|
| **육성우 감축률이 전부다** | BCR 민감도 1위. 15%인지 45%인지에 따라 편익이 3배 차이. **파일럿의 1번 측정 항목**으로 삼는 이유 |
| **젖소 두당 4.2톤은 유도값** | 공표된 두당 배출계수가 아니라 총량·기여율에서 역산했다. 유도 과정을 공개했으니 검증 가능 |
| **육성우 두당 3톤은 가정** | 성우 평균 4.2톤보다 낮게 잡은 보수값. 육성우 전용 계수 확보 필요 |
| **탄소 사회적비용 10만원/톤** | 시장가의 10배. **시장가 기준도 반드시 병기**. BCR 영향은 실제로 가장 작다 |
| **감축분의 귀속** | 농가 감축인가 지자체 실적인가. **배출권·인센티브 제도 정합 검토 필요** |
| **리바운드 효과** | 두수가 줄어 여유가 생기면 다시 늘릴 수 있다. 쿼터·정책 설계로 관리해야 |

> 마지막 두 개는 **정책 설계 과제**다. 우리가 답할 수 없고, 답하는 척하면 안 된다.
> "이건 제도 설계 영역이고, 저희는 측정과 근거를 제공하겠습니다"가 정확한 답이다.

## 7. 한 장으로 정리하면

```
왜        축산은 2030년까지 온실가스 30%를 줄여야 하는데
          감축 수단이 구조적으로 부족하다

무엇을    한 마리가 덜 배출하게 하는 대신
          같은 우유를 더 적은 소로 생산하게 만든다

어떻게    번식효율↑ · 생애수명↑ → 대체 후보축 수요↓
          (CowTalk이 이미 하고 있는 일 — 새로 할 일이 없다)

그래서    경기 젖소 부문 2030 감축목표의 13~38% 달성
          분뇨 연 6.4~19.3만톤 감소 → 악취 민원 직접 완화
          사료비 96~289억 절감 → 농가는 돈을 벌면서 감축한다
```

> **가장 강한 한 문장**:
> **"농가에 비용을 부담시키지 않고 축산 온실가스를 줄이는 거의 유일한 수단입니다."**
