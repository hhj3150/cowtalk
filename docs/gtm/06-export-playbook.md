# 해외 수출 플레이북
## 1순위: 동남아 (베트남·인도네시아·태국) / 중동·중앙아시아 (UAE·사우디·우즈베키스탄)

> **수출 명제**: 우리가 파는 것은 소프트웨어가 아니라
> **"국가 축산 운영체제를 자국 영토 안에 설치하는 방법"**이다.
> 데이터는 그 나라에 남고, 우리는 그것을 해석하는 두뇌를 제공한다.

---

## 1. 왜 이 두 권역인가

| 권역 | 기회 | 진입 방식 | 난이도 |
|---|---|---|---|
| **동남아** | 구제역·럼피스킨 상재, 축산 성장기, ODA/KSP 수혜 대상, 한국 축산 기술 신뢰도 높음 | 공적자금 파일럿 → 유상 확산 | 중 |
| **중동·중앙아** | 식량안보 국가 어젠다, 국부펀드 재원, 정부 주도 대형계약, 낙농 자급 정책 | 국가 라이선스 직접 계약 | 중상 |

**의도적으로 후순위로 둔 곳**
- **유럽·오세아니아**: smaXtec 본거지. 센서는 이미 깔려 있고 우리 파트너의 시장이다.
  → 채널 충돌 위험. AI·행정 레이어만 얹는 애드온 전략으로 **나중에** 접근한다.
- **중남미**: 대규모 시장이나 smaXtec 기존 시장과 중첩, 지리·언어 비용 큼.

## 2. 권역 A — 동남아

### 2-1. 무엇으로 문을 여는가: **방역**

동남아 정부의 최우선 관심사는 생산성이 아니라 **전염병 차단**이다.
구제역(FMD), 럼피스킨(LSD), 아프리카돼지열병이 상시 위협이고,
한 번 돌면 국가 경제에 타격이 온다.

> **오프닝 문장**:
> "We are not here to sell you a farm app. We are here to show you how a country
> can see an outbreak **before it is reported.**"

**시연 순서 (동남아용)**
1. 전국 상황판 → 시도 드릴다운 (지휘 감각)
2. 집단 발열 감지 → 접촉망 추적
3. **SEIR 확산 시뮬레이션 — 이동제한 있음/없음 비교**
4. 역학조사 워크플로 → 국가 보고 체계 연계
5. (마지막에) 농가 개체 화면 — "이 모든 게 소 한 마리에서 시작합니다"

### 2-2. 국가별 카드

| 국가 | 축산 특성 | 진입 경로 | 주의점 |
|---|---|---|---|
| **베트남** | 낙농 급성장(대기업 대형목장 + 소농 혼재), 정부 디지털 전환 강력 추진 | 대형 낙농기업 파일럿 → 정부 확산 / KSP | 대기업이 자체 시스템 보유 → 통합 vs 대체 포지셔닝 명확히 |
| **인도네시아** | 육우 수입 의존 → 자급 정책, 광대한 도서 지역 | 정부 자급 정책 연계, ODA | 통신 인프라 편차 큼 → 오프라인 내성 필요 |
| **태국** | 낙농협동조합 발달, 축산 수출국 | 협동조합 단위 도입 → 확산 | 조합이 의사결정 주체. 정부만 보면 실패 |

### 2-3. 재원 — 이것이 동남아 진입의 실질 관문

| 재원 | 성격 | 활용법 |
|---|---|---|
| **KSP** (경제발전경험공유사업) | 정책 자문 | 축산 디지털 전환 정책 컨설팅으로 진입, 시스템은 후속 |
| **ODA / EDCF** | 무상·유상 원조 | 파일럿 구축비 조달 |
| **KOICA 혁신적기술프로그램** | 기술 실증 | 소규모 실증사업 |
| **글로벌 기금** (FAO/OIE-WOAH 관련) | 방역 역량 강화 | 방역 축으로 접근 시 유리 |

> **권장 진입 순서**: KSP(정책) → ODA(파일럿 구축) → 국가 예산(확산)
> **절대 하지 말 것**: 첫 미팅에서 가격표를 꺼내는 것. 동남아는 **재원 설계가 먼저**다.

### 2-4. 기술 현지화 과제

| 과제 | 내용 | 난이도 |
|---|---|---|
| 품종 | 물소(buffalo), 제부(zebu), 교잡종 → 생리 파라미터 재설정 | 중 (파라미터화 되어 있음) |
| 기후 | 고온다습 → THI 임계값 재보정 | 중 |
| 통신 | 농촌 네트워크 불안정 → 오프라인 큐잉·재전송 | **상 (신규 개발 필요)** |
| 이력제 | 국가별 상이·부재 → 커넥터 신규 또는 자체 등록 대체 | 중 |
| 언어 | 베트남어·인니어·태국어 UI + AI 응답 | 중 (i18n 선행 필요) |
| 규모 | 소농 다수 → 농가당 두수 적음 → **단가 구조 재설계 필수** | 상 |

> ⚠️ **가장 큰 함정**: 두당 15,000원 구조를 그대로 가져가면 동남아에서는 팔리지 않는다.
> 소농은 5~20두 규모다. **농가 단위 정액 요금 + 협동조합/기업 단위 묶음 계약**으로 재설계한다.

## 3. 권역 B — 중동·중앙아시아

### 3-1. 무엇으로 문을 여는가: **식량안보**

중동 산유국의 축산 정책은 경제성 논리가 아니라 **국가 안보 논리**로 움직인다.
"우유를 수입에 의존하지 않겠다"는 것이 국가 어젠다다.
그래서 **BCR을 설득할 필요가 상대적으로 적고, 규모는 크다.**

> **오프닝 문장**:
> "Food security is not an agricultural policy — it is a national security policy.
> This system gives your government real-time visibility over national dairy production."

**시연 순서 (중동용)**
1. 국가 단위 상황판 — 규모감부터
2. **데이터 주권 아키텍처** (여기서 시간을 가장 많이 쓴다)
3. 대형 목장 개체 관리 — 열 스트레스(THI) 관리 강조
4. 생산성 지표 — 자급률에 직결되는 산유량·번식효율
5. 방역 — 수입 가축 검역 연계

### 3-2. 국가별 카드

| 국가 | 특성 | 진입 경로 | 주의점 |
|---|---|---|---|
| **UAE** | 초대형 낙농(사막형 대규모 목장), 기술 도입 적극, 규제 유연 | 정부 혁신부처·대형 낙농기업 직접 | 경쟁사 선점 빠름. 속도가 관건 |
| **사우디** | Vision 2030 식량안보, 세계 최대급 사막 낙농 | 국부펀드·정부 프로젝트 | 현지 파트너십 의무 요건 확인 필요 |
| **우즈베키스탄** | 축산 진흥 정책, 한국과 협력 관계 양호, 중앙아 교두보 | 정부 간 협력 + ODA 혼합 | 지불 여력 제약 → 혼합 재원 설계 |

### 3-3. 중동 특화 기술 과제

| 과제 | 내용 |
|---|---|
| **극한 열 스트레스** | 사막 기후 THI 재정의. 냉방·미스트 시스템 연계 제어 수요 |
| **초대형 목장** | 단일 목장 수천~수만 두 → 대량 처리·그룹 관리 UI 강화 |
| 언어 | 아랍어 (RTL 레이아웃 — **UI 구조 변경 필요, 난이도 상**) |
| 규제 | 현지 데이터 보관 의무, 정부 클라우드 지정 |
| 종교·문화 | 할랄 인증 연계 이력 관리 수요 |

> **RTL(우→좌) 레이아웃은 i18n보다 훨씬 비싸다.** 아랍어 계약이 확정된 후에 착수한다.
> 초기 제안은 **영어 UI**로 진행 가능하다 (중동 정부 실무진 영어 사용).

## 4. 진입 모델 4종 — 어떤 나라에 무엇을

| 모델 | 구조 | 적합 | 수익 |
|---|---|---|---|
| **A. 국가 라이선스** | 국가 단위 연간 고정 + 소버린 인스턴스 구축비 | 중동 (정부 재원 충분) | 대형·선불 |
| **B. 두당 로열티** | 현지 파트너 운영, 두당 로열티 수취 | 동남아 확산기 | 반복·후행 |
| **C. ODA/KSP 연계** | 공적자금으로 구축, 이후 운영 전환 | 동남아 진입기 | 구축비 + 전환 |
| **D. 화이트라벨** | 현지 브랜드로 공급, 코어는 D2O | 대형 현지 기업 존재 시 | 로열티 |

**권장 조합**
- 동남아: **C → B** (공적자금 파일럿으로 실적 만들고 유상 확산)
- 중동: **A** (처음부터 국가 계약)

## 5. 소버린 배포 아키텍처 (해외 발표 핵심 슬라이드)

```
        ┌──────────────────────────────────────┐
        │  CowTalk Core (D2O, Korea)           │
        │  단일 코드베이스 · 어댑터 패턴         │
        └──────────────┬───────────────────────┘
                       │  코드·업데이트만 전달
                       │  (데이터는 흐르지 않음)
      ┌────────────────┼────────────────┐
      ▼                ▼                ▼
┌───────────┐   ┌───────────┐   ┌───────────┐
│ 🇻🇳 VN      │   │ 🇦🇪 UAE     │   │ 🇺🇿 UZ      │
│ Sovereign │   │ Sovereign │   │ Sovereign │
│ Instance  │   │ Instance  │   │ Instance  │
├───────────┤   ├───────────┤   ├───────────┤
│ 현지 DB    │   │ 현지 DB    │   │ 현지 DB    │
│ 현지 연산  │   │ 현지 연산  │   │ 현지 연산  │
│ 현지 감사  │   │ 현지 감사  │   │ 현지 감사  │
└───────────┘   └───────────┘   └───────────┘
  데이터 국내 잔류   데이터 국내 잔류   데이터 국내 잔류

  ── 반출 경계 (Export Boundary) ─────────────────
  나가는 것:  익명화·집계 통계 (해당국 승인 시에만)
  나가지 않음: 원시 센서, 개체 식별정보, 농가 정보, 진료기록
```

**이 슬라이드를 영어 한 문장으로 요약**
> "Code flows out. Data never does."

## 6. 현지화 체크리스트 (신규 국가 착수 시)

### 필수 (없으면 서비스 불가)
- [ ] 언어 — UI + AI 응답 (i18n)
- [ ] 품종·생리 파라미터 (임신기간·발정주기·번식 설정)
- [ ] 기후 THI 임계값 재보정
- [ ] 통화·단위·날짜 형식
- [ ] 데이터 보관 위치 법적 요건 확인
- [ ] 개체 식별 체계 (이력제 유무·형식)

### 중요 (없으면 가치 반감)
- [ ] 국가 방역 보고 체계 연계
- [ ] 현지 기상 데이터 소스
- [ ] 현지 종모우·유전자원 데이터
- [ ] 시세·경락 데이터
- [ ] 현지 약제·휴약기간 기준

### 운영
- [ ] 현지 파트너 선정·인증
- [ ] 현장 교육 프로그램 현지어화 (T4 → 현지어)
- [ ] 기술지원 시차 대응 체계
- [ ] 결제·정산 구조

## 7. 경쟁 환경

| 경쟁 유형 | 예 | 우리의 차별점 |
|---|---|---|
| 글로벌 센서 회사 | smaXtec, Allflex, Nedap | **파트너다.** 우리는 그 위층 |
| 목장관리 SW | 각국 로컬 솔루션 | 센서 데이터 자동 유입 + AI 해석 + 방역 |
| 국가 방역 시스템 | 각국 자체 구축 | 신고 이전 조기감시 레이어 |
| 대형 IT/컨설팅 | 글로벌 SI | **축우 몸속 데이터 + 4역할 + 실제 운영 실적** |
| 중국 스마트축산 | 저가 공세 | 데이터 주권 우려 → **한국은 지정학적으로 안전한 선택** |

> **지정학 카드**: 동남아·중동 정부에게 "한국은 데이터 주권 측면에서 안전한 파트너"라는
> 포지션은 실질적 경쟁우위다. 명시적으로 말하지 말고 **소버린 아키텍처로 보여준다.**

## 9. 해외 발표에서 절대 하지 말아야 할 5가지

1. **한국 제도를 전제로 설명하기** — "이력제 번호 12자리"는 그 나라에 없다
2. **한국 가격 그대로 제시** — 동남아엔 비싸고 중동엔 싸다
3. **"세계 최고" 류의 형용사** — 정부 관계자는 형용사를 신뢰하지 않는다
4. **데이터 주권 질문을 뒤로 미루기** — 먼저 말하지 않으면 방어로 보인다
5. **못 하는 것을 숨기기** — 파일럿에서 드러나면 그때는 회복이 불가능하다
