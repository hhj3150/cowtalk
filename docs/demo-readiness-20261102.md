## 3. 동물복지 관점 — 기능 지도 (Five Domains)

복지 점수/지수는 아직 없음. 그러나 **실데이터로 작동하는 복지 기능은 충분**하다.

| 영역 | 작동 중인 기능 | 화면 |
|---|---|---|
| 영양 (배고픔·갈증) | 음수량(전일 L), 위내온도 하강으로 추정한 24h 음수 횟수, 반추 24h 평균, 사료 이상 알람(반추↓·체온 정상) | `/cow/:id`, `/feed-ration` |
| 환경 (열스트레스) | 기상청 실측 THI → 78↑ 폭염 대응 결정 카드, 84↑ 긴급 / `query_weather` 권고 | 대시보드 결정 카드 |
| 건강 (조기발견·통증) | 건강 점수(♥), 케토시스·유방염·산독증·제엽염·유열·후산정체·기립불능 알람 + 액션플랜, 감별진단, 치료 전후 센서 비교 회복 판정, 휴약기간 계산 | `/cow/:id`, 알람 피드 |
| 행동 | 체온·활동·반추 차트 + 이벤트 마커, 발정 주기 예측 | `/cow/:id`, `/breeding` |
| 정서 (스트레스) | 직접 기능 없음 — 반추 저하·활동 급변·분만 전 불안이 대리 지표 | — |
| 분만 안전 | 분만 예측(체온 하강+활동) → 분만실 이동·초유 준비 권고, 분만 워크플로·신생우 체크리스트 | `/cow/:id`, 분만 위젯 |

### 추천 시연 동선 ("한 마리 소" 이야기)
1. **아픈 소 → 회복**: 알람 피드(케토시스/유방염 + 이유·조치) → `/cow/:id` (건강 점수·센서 차트·감별진단) → 팅커벨 "이 소 왜 아파?" → 치료 기록(휴약 자동 계산) → 치료 전후 센서 비교 "회복"
2. **폭염**: THI 결정 카드(기상청 실측) → 체온↑·반추↓ 개체 → 팅커벨 열스트레스 권고
3. **분만 안전**: 분만 알람 → 분만 임박 예측 → 분만 워크플로·신생우 체크리스트
4. **물과 밥**: 음수량·음수 횟수 KPI를 위내온도 V자 하강으로 설명 → 사료 이상 알람

⚠️ 시연 개체는 센서 차트에 **'추정치' 라벨이 없는 소**로 미리 골라 둔다.
